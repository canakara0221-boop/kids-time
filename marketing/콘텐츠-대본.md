# 릴스·캐러셀 콘텐츠 대본 (바이럴 시드)

목표: 감정 훅으로 **저장·공유** 유도 → 프로필 링크(계산기)로 유입 → 이메일 신청.
플랫폼: 인스타 릴스 / 유튜브 쇼츠 / 틱톡. 세로 9:16.

---

## 🎬 릴스 대본 (메인) — "잔인한 시간"

### 훅 (0~2초, 제일 중요 — 4개 중 A/B 테스트)
- **A(질문·저장유도)**: "우리 애랑 함께 보낼 '주말', 몇 번 남았을까?"
- **B(충격 통계)**: "자식과 평생 함께하는 시간의 80%는 — 18살 전에 끝납니다."
- **C(공감·유통기한)**: "아이가 '놀자'며 먼저 다가오는 시간, 딱 10년 남았어요."
- **D(개인화)**: "생일만 넣으면 우리 애와 남은 시간이 나옵니다."
> 추천 시작: **A 또는 D**(질문·개인화가 저장/댓글 유도 강함). B는 도달은 크나 무거움.

### 본문 (2~14초) — 자막 하나씩 등장 (원본 이미지 리듬)
1. 부모 말이 먹히는 나이 … **6~12세**
2. 손잡고 걸어줄 수 있는 기한 … **9세까지**
3. 품에서 같이 잠드는 시간 … **딱 10년**
4. "놀자"고 먼저 다가오는 유통기한 … **10년뿐**
5. 함께 보낼 여름방학 … **평생 12번**
6. 함께하는 시간의 **80%는 18세 전에 끝남**

### 전환 (14~19초)
- 자막: "그래서 **우리 애는 지금 얼마나 남았나** 계산해봤어요"
- 화면: 계산기에 생일 입력 → **"함께 보낼 주말 689번 남음"** 결과 카드 뜨는 장면(화면녹화)

### CTA (19~25초)
- 자막: "**너희 아이는 며칠 남았어?**"
- "생일만 넣으면 1초 — 프로필 링크 👆"
- 끝 화면: 계산기 결과 카드 + "@계정 · 우리 아이와 남은 시간"

### 오디오
- 잔잔한 감성 피아노 (예: 원본이 쓴 'mellozen — 이 순간이 소중해' 류). 트렌딩 감성 BGM 우선.

### 캡션(본문 글)
```
아이와 함께할 수 있는 시간은 생각보다 짧습니다.

'놀자'고 먼저 달려오는 것도 10년뿐,
함께 보낼 여름방학은 평생 12번.

우리 애는 지금 얼마나 남았을까 궁금해서 계산기를 만들었어요.
생일만 넣으면 남은 주말·여름방학이 나옵니다. (프로필 링크 👆)

오늘, 딱 10분만 같이 놀아줄까요? 🧸
👉 저장해두고 주말에 아이랑 보세요.

#육아 #아들맘 #딸맘 #워킹맘 #육아스타그램 #부모 #아이와함께 #감성육아 #자녀교육 #오늘도육아
```

### 고정 댓글 (핀)
```
🔗 계산기 → 프로필 링크 클릭
너희 아이는 며칠 남았는지 댓글로 알려줘요 👇 (저장 필수!)
```

## 🖼️ 캐러셀 (8장) — 넘겨보는 버전

1. (커버) **자식과 함께할 수 있는 '잔인한 시간' ⏰** / "끝까지 넘겨보세요 →"
2. 부모 말이 먹히는 나이 — **6~12세**
3. 손잡고 걸어줄 수 있는 기한 — **9세까지**
4. 품에서 같이 잠드는 시간 — **딱 10년**
5. "놀자"고 먼저 다가오는 유통기한 — **10년뿐**
6. 함께 보낼 여름방학 — **평생 12번** / 함께하는 시간 80%는 18세 전에 끝
7. **"그래서 우리 애는 얼마나 남았지?"** → (계산기 결과 캡처: 주말 689번)
8. (CTA) **생일만 넣으면 1초** / "프로필 링크에서 계산 → 저장·공유" / @계정

> 캐러셀 캡션은 위 릴스 캡션 재사용.

---

## 🧪 배포·측정 플랜
- **주 2~3개** 올리며 훅 A/B (같은 본문, 첫 자막만 교체).
- 측정 지표: **저장수 > 공유수 > 댓글 > 링크클릭 > 이메일신청**. 저장·공유가 알고리즘·바이럴의 핵심.
- 반응 좋은 훅으로 몰아주고, 나쁜 건 버림. 1~2주 안에 "이게 퍼지나" 판가름.
- 링크 유입 대비 **이메일 신청률**이 검증 KPI(관심의 실증). 낮으면 훅은 좋아도 제품수요 약함 → 방향 재고.

## ⚠️ 톤 주의
- "잔인한/유통기한" 프레임은 도달엔 강하나 **죄책감 유발** 소지 → 끝은 반드시 **따뜻한 행동 제안**("오늘 10분만 같이")으로 닫기. 불안만 남기면 공유는 되도 브랜드 호감·리텐션은 떨어짐.
