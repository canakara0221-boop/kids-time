# 알림 시스템 설치 (구글 Apps Script · 서버·비용 0)

이메일 대기자 수집 + 주간(또는 매일) 알림 발송을, **서버·요금 없이** 구글로 돌립니다.
구글 계정 로그인·배포는 직접 하셔야 해요(아래 5단계, 약 10분).

## 1. 스프레드시트 + 스크립트 만들기
1. [sheets.new](https://sheets.new) 로 새 구글 시트 생성 (이름: 예 `kids-time-구독자`)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 기본 `Code.gs` 내용을 전부 지우고, 이 폴더의 **`Code.gs`** 내용을 통째로 붙여넣기 → 💾 저장

## 2. 웹앱으로 배포 (수집 endpoint 만들기)
1. 오른쪽 위 **배포 → 새 배포**
2. ⚙️(유형 선택) → **웹 앱**
3. 설정:
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**  ← (사이트에서 익명 POST 받아야 하므로)
4. **배포** → 권한 승인(본인 구글 계정, "고급 → 안전하지 않음으로 이동" 눌러야 할 수 있음)
5. 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/AK..../exec`)

## 3. 사이트에 URL 연결
- `index.html` 에서 이 줄을 찾아 URL을 붙여넣기:
  ```js
  const WAITLIST_ENDPOINT = "";  // ← 여기에 웹앱 URL
  ```
  →
  ```js
  const WAITLIST_ENDPOINT = "https://script.google.com/macros/s/AK..../exec";
  ```
- 저장 후 깃 푸시하면(아래) 라이브 사이트에 반영됩니다. 이제 이메일 신청이 시트에 쌓여요.

## 4. 발송 트리거 걸기 (주1회 or 매일)
1. Apps Script 편집기 왼쪽 **⏰ 트리거(시계 아이콘)** → **트리거 추가**
2. 설정:
   - 실행할 함수: **sendReminders**
   - 이벤트 소스: **시간 기반**
   - **주간 타이머**(추천 · 토요일 오전 9시) 또는 **일일 타이머**(매일)
3. 저장 → 이제 자동 발송.
   - ※ 먼저 `testSendToMe` 함수를 한 번 실행해 **본인 메일로 테스트 1통** 받아보세요.

## 5. 완료 체크

- [ ] `testSendToMe` 실행 → 내 메일함에 예쁜 알림이 오나?
- [ ] 트리거가 등록됐나?

## 채널 확장 (나중에)
- **📧 이메일 (지금 이 방식)**: 무료·즉시. gmail 하루 100통 한도(구독자 그 이하면 충분).
- **📱 문자(SMS)**: 유료(건당 ~₩8~20). 솔라피/알리고/NHN Cloud 가입 → Apps Script에서 `UrlFetchApp`으로 API 호출로 교체.
- **💬 카카오 알림톡**: 한국 유저엔 최고지만 **카카오 비즈니스 채널 + 템플릿 사전심사 + 발송대행사(솔라피 등) + 대개 사업자등록** 필요 → 검증 후 3단계로.

## 발송 주기 · 톤 권장
- **매일보다 "주간"(토요일 아침) 추천**: 매일 "남은 시간 줄어듦"은 죄책감·불안이 됨(감정 무거움). 주말 직전 "이번 주말 남은 N번 중 하나 — 뭐하고 놀까?"가 따뜻하고 행동으로 이어짐.
